# Release Notes

## v2.0.0 (2026-03-07)

- フロント全体のビジュアルを再設計し、hero / 2カラム構成 / カード / 比較表 / モーダルの見た目を整理。
- 比較表のレスポンシブ表示を見直し、全券種比較はモバイルで横スクロール前提の表示へ変更。列幅や折り畳みUI、`info` の配置も調整。
- 分析操作を「再分析」と「データ更新」に分離し、取得状態を分析設定欄に要約表示。フロントキャッシュ / サーバーキャッシュ / 最新取得の区別と時刻情報を見やすく改善。
- 馬番表記を丸数字へ統一し、消し馬ピッカーを含む細部の可読性を改善。

## v1.5.0 (2026-03-07)

- 比較表の各行から、列ごとの比例資金配分モーダルを開けるように改善。
- 買い目一覧を省略せず、スクロール可能な表形式で表示。
- 購入金額を行ごとに編集できるようにし、実現オッズ・払戻し額を即時計算。
- 配分表はオッズ順などで並び替え可能にし、拡張パターンはトグル切り替え表示へ整理。

## v1.4.0 (2026-03-07)

- 中央 / 地方 / 海外タブのレース選択UIを追加し、中央・地方は当日レースを1ボタンで分析可能に。
- 日付 + 開催場からのレース選択を追加し、必要時のみ開く折りたたみ構成へ整理。
- 今日の開催場一覧は会場タブ切り替えに変更し、スマホでの縦長化を軽減。
- URL入力を副機能へ移動し、案内文を整理。冒頭概要と `info` 文面も現行仕様に合わせて更新。

## v1.3.0 (2026-03-04)

- URL入力の受理範囲を拡張（`race_id` があれば出馬表/オッズ/SPなどページ種別を問わず受付）。
- `race.sp.netkeiba.com` を自動正規化し、内部で出馬表URLへ統一。
- 計算責務をフロントへ移管（backendはスクレイプ結果返却中心）。
- 同一URLの再計算をフロントキャッシュで実行（メモリ + `sessionStorage`）。
- ドキュメント（README / architecture / API契約）を現行設計に更新。

## v1.2.0 (2026-03-02)

- `c1` 拡張表示で「馬単2着 vs 3単2着付」の行比較ハイライトを追加。
- 1着付比較とは別色で表示して見分けやすく改善。

## v1.1.0 (2026-03-01)

- 分析結果テーブルをクライアント側で `CSV` / `HTML` 出力可能に。
- 出力は再計算せず、直近の分析結果を再利用。

## v1.0.0 (2026-02)

- 比較UIを実運用向けに整理（固定列、フィルタ、拡張表示など）。
- 全券種比較・c1〜c6の表示運用を安定化。

## v0.4.0 (2026-02)

- 表示基盤の改善（馬表示列幅の調整など、可読性向上）。
