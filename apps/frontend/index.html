nk-calculator

netkeibaレースURLからオッズを比較します。

対応URL: netkeiba の出馬表ページ（`race.netkeiba.com` / `nar.netkeiba.com` の `/race/shutuba.html?race_id=...`）

レース選択はこちらから: https://race.netkeiba.com/top/

info（仕様と説明）

仕様（計算ルール）

  • 対応URLは `race.netkeiba.com` / `nar.netkeiba.com` の出馬表URL（`/race/shutuba.html?race_id=...`）です。
  • 合成オッズは、対象買い目の確率和から逆算します（合成オッズ = 1 / Σ(1 / 各オッズ)）。
  • レンジ表記オッズ（例: 10.5 - 12.8）は平均値で計算します。
  • 0倍は計算上 999999倍として扱います。
  • 差異率は、基準列（左端）に対する最大列の比率で計算します。

説明（読み方と使いどころ）

  • 単勝系・複勝系など、同じ行で比較している馬券は「当たり方が論理的に同じ」組み合わせです。
  • 差異率が大きい行は、実際には極端な穴馬を含むことが多く、単純に「買い得」とは限りません。
  • 人気馬を消し馬にすると連勝系の合成オッズが跳ねやすく、穴馬を消すと単勝系が相対的に優位になりやすい傾向があります。
  • 絞り込みで馬A/馬Bを選ぶと、相手馬（または残り1頭）に絞って確認できます。

合成オッズの説明

  • 固定オッズを前提に、比較先の合成オッズが基準より高い場合は、比例配分（1/オッズ配分）によって「任意の的中結果で基準の払戻しを上回る」買い方を理論上構成できます。
  • パラドキシカルな具体例（単勝1点 vs 馬単8点）: 単勝A=3.6、馬単は A→B/C/D/E/F/G/H/I の8点で、オッズを 18/22/25/28/35/40/55/70 とします。
  • 総額10万円を馬単8点へ傾斜配分（21100/17300/15200/13600/10900/9500/6900/5500円）すると、各結果の払戻しは 379500〜385000円になります（最小でも379500円）。
  • 同額10万円を単勝A1点に入れた払戻しは 100000×3.6=360000円なので、1点あたり資金が薄くなっても、Aが1着になる全結果パターンで馬単8点のほうが上回ります。
  • ただし実運用では、オッズ変動と購入単位（通常100円）による丸めで理論どおりにならない場合があります。
  • 資金配分は `1/オッズ` 比例で行うと、合成オッズに近い配分になります（100円単位で最終調整）。
